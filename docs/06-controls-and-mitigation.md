# 06 - Controls and Mitigation

## Recommended Controls

### Access Control

* Implement Role-Based Access Control (RBAC)
* Enforce Multi-Factor Authentication (MFA)

### Monitoring

* Enable logging of user activities
* Implement monitoring tools for anomaly detection

### Governance

* Define security policies and procedures
* Assign roles and responsibilities

### Compliance

* Align controls with ISO 27001 framework
* Implement GDPR data protection measures

## Risk Mitigation Mapping

| Risk                | Control                  |
| ------------------- | ------------------------ |
| Unauthorized access | RBAC + MFA               |
| Data breach         | Monitoring + encryption  |
| Compliance risk     | Policies + GDPR controls |

## Conclusion

Implementing these controls will significantly reduce risk exposure.
