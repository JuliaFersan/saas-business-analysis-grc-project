# 03 - Process Mapping

## Current Process: User Onboarding

1. User signs up on the platform
2. Request is manually reviewed
3. IT team manually creates account
4. Access is granted without role validation

## Identified Issues

* Manual process creates delays
* No standardized approval workflow
* Lack of role-based access control (RBAC)
* No logging or monitoring of access

## Risk Exposure

* Unauthorized access to sensitive data
* Human errors during onboarding
* Lack of audit trail

## Future State (High-Level)

* Automated onboarding system
* Role-based access control implementation
* Approval workflow with defined roles
* Logging and monitoring enabled
